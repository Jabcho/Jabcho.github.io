Postman은 API를 사용하고, 구현하고, 테스트할 수 있는 API 플랫폼입니다. 데스크톱 앱 하나로 API 라이프사이클 전 과정을 관리할 수 있습니다.

- HTTP·GraphQL·gRPC 등의 요청을 Postman API 클라이언트로 전송합니다.

- API를 설계하고, 구현하고, 문서화합니다.

- LLM 및 API와 상호작용하는 AI 에이전트 구축합니다.

- API의 기능 및 성능을 테스트하고 모니터링합니다.

- API 개발 작업을 체계화하고 팀원들과 협업합니다.

- 새로운 API를 탐색하고 시각적 API 기반 애플리케이션을 제작합니다.

Postman은 데스크톱 및 웹 앱으로 제공됩니다.

- 데스크톱 앱 다운로드: [Download Postman 페이지](https://www.postman.com/downloads/)에서 사용하는 운영체제에 맞는 앱을 다운받으세요. Postman은 macOS(인텔 및 애플 실리콘), Windows(인텔 64비트), Linux(64비트)용 네이티브 데스크톱 앱을 제공합니다.

- 브라우저에서 시작: [웹 앱](https://identity.getpostman.com/login?)으로 이동하세요.

[Postman 웹 앱]({% link _apis/postman/docs/02/04_install/installation_and_updates.md %}#web-limitations)에서는 일부 기능이 지원되지 않습니다. 모든 기능을 사용하려면 데스크톱 앱을 이용하세요.

설치와 관련된 도움이 더 필요하면 [Install and update Postman]({% link _apis/postman/docs/02/04_install/installation_and_updates.md %}) 문서를 참고하세요.
