# Get started in Postman
<br>
환영합니다! 이 섹션에는 Postman을 처음 사용할 때 알아두면 좋은 주제를 포함한 Postman Docs를 모아 놓았습니다.

Postman을 빠르게 시작해 보려면 [Postman 첫걸음](#your-first-steps-with-postman)을 확인하세요. 요청 보내기, 테스트 스크립트 작성, 협업하기 등 기본 사용법을 익힐 수 있습니다.

Postman에 대해 더 배우고 싶다면 다음 주제 중 하나로 바로 이동하여 확인할 수 있습니다.

-  요청 보내기 등 Postman에서 다양한 작업을 시작하려면 [Postman 데스크톱 앱](https://www.postman.com/downloads/)을 다운받아 설치하세요. 자세한 내용은 [Postman 설치 및 업데이트]({% link _apis/postman/docs/02/04_install/installation_and_updates.md %})를 참고하세요.

- 앱을 열었으면 [Postman 둘러보기]({% link _apis/postman/docs/02/02_basics/the_postman_interface.md %})를 먼저 확인해 보세요.인터페이스에 익숙해졌다면, [첫 번째 요청 보내기]({% link _apis/postman/docs/02/01_first/send_a_request.md %})를 시도해 보세요.

- Postman 계정을 만들고 [계정 관리](#your-postman-account)와 [Postman 프로필 커스터마이징]({% link _apis/postman/docs/02/04_install/customize_your_profile.md %}), [초기 설정 방법]({% link _apis/postman/docs/02/04_install/settings.md %})을 알아보세요.

- Postman API Network에서 필요한 API를 찾아볼 수 있습니다. [Postman API Network에서 공개 API 탐색하기]({% link _apis/postman/docs/02/01_first/explore_the_postman_api_network.md %}) 문서에서 사용 방법을 확인하세요. [Postman API](https://www.postman.com/postman/postman-public-workspace/documentation/i2uqzpp/postman-api)도 여기에서 찾을 수 있습니다.

- 요청을 몇 개 만들었다면 [첫 컬렉션 만들기]({% link _apis/postman/docs/02/01_first/create_a_collection.md %})로 묶어 관리해 보세요.

- 또한 Postman으로 다른 곳에서 만든 요청과 데이터를 불러오거나, 내보내기로 다른 프로그램에서 사용할 수 있습니다. [데이터 가져오기 및 내보내기](#import-and-export-data)를 참고하세요.

- 문제가 생겼나요? [앱 문제 해결하기]({% link _apis/postman/01.md %}#troubleshoot-issues-with-the-postman-app)를 확인하세요.

# Postman basics

## Postman basics overview
이 섹션에서는 Postman의 기본 기능을 다룹니다. 이 기능들을 이용하면 API 요청을 보내고, 다른 사람들과 작업을 공유하며, Postman을 API 개발 워크플로우에 활용할 수 있습니다. Postman 사용자 인터페이스를 둘러보며 API-First 개발 여정을 시작해보세요.

### Find your way around Postman
Postman에는 API를 다루고 팀과 협업하기 위한 다양한 도구가 있습니다. 필요한 기능을 언제든 쉽게 찾을 수 있도록 [Postman을 탐색하는 방법]({% link _apis/postman/docs/02/02_basics/the_postman_interface.md %})을 배워보세요.

도움이 더 필요하신가요? API 워크플로우를 도와줄 AI 어시스턴트, Postbot을 이용해보세요. 요청을 보낼 때 테스트를 추가하거나, 응답을 시각화하거나, 문서를 작성하는 등의 작업을 [Postbot에게 물어볼]({% link _apis/postman/docs/02/02_basics/postbot.md %}) 수 있습니다.

### Discover Postman elements
Postman을 이용해 API 개발 과정을 효율화하는 법을 알아보세요. [Postman 요소(Elements)]({% link _apis/postman/docs/02/02_basics/postman_elements.md %})에서는 컬렉션(Collections), 요청(Requests), 문서화(Documentation), 환경(Environments), 플로우(Flows), API Builder, Spec Hub, 모의 서버(Mock Servers), 모니터(Monitors) 등의 의미와 사용 방법을 설명합니다.

### Send API requests from Postman
[Postman Agent]({% link _apis/postman/docs/02/02_basics/the_postman_agent.md %}#select-a-postman-agent-for-requests)를 사용하면 Postman 웹 앱에서 브라우저를 통해 API 요청을 보낼 수 있습니다. 직접 에이전트를 선택할 수도 있고, Postman이 자동으로 가장 적합한 에이전트를 선택하도록 할 수도 있습니다.

Postman 계정에 로그인하지 않아도, [경량 API 클라이언트]({% link _apis/postman/docs/02/02_basics/lightweight_api_client.md %})를 통해 다수 프로토콜 기반의 요청을 보낼 수 있습니다.

### Save and share your work in Postman
Postman 계정에 로그인하면 모든 작업이 [자동으로 Postman 클라우드에 동기화]({% link _apis/postman/docs/02/02_basics/syncing.md %})됩니다. 따라서 어떤 환경에서든 Postman 계정에 로그인하면 자신의 컬렉션, 요청, 그 외 모든 데이터에 접근할 수 있습니다.

또한 [Postman 협업 도구]({% link _apis/postman/docs/02/02_basics/collaboration_basics.md %})를 통해 팀원들과 작업을 공유할 수도 있습니다. Postman 데이터를 팀 워크스페이스로 옮기면 다른 사람들과 함께 협업을 시작할 수 있습니다.
